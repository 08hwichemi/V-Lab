# V-Lab 디자인 가이드

## 원칙

1. **글자·선·썸네일로만 구성한다.** 색 배경 타일, 그라데이션, 장식 도형, 이모지는 쓰지 않는다.
2. **밝은 바탕에 검정 포인트 하나.** 버튼은 검정(주요)·흰색+1px 선(보조) 두 가지뿐이다. 파랑(#3182F6)은 수치·링크·슬라이더처럼 "값"을 뜻할 때만 쓴다.
3. **과목색은 작은 점에만.** 카드 메타 줄 앞 6px 점, 뷰어 보조 바의 점. 큰 면적에 과목색을 칠하지 않는다.
4. **한 화면에 들어오게.** 홈·과목 페이지는 1440×900 에서 스크롤 없이 12~15개 카드가 보이는 밀도를 유지한다.
5. **실험 안과 밖이 같은 언어.** 실험 HTML 도 같은 글꼴·색·버튼을 쓴다 (`assets/css/lab-theme.css`).

## 토큰

| 용도 | 값 |
|---|---|
| 글꼴 | IBM Plex Sans KR (본문·제목), IBM Plex Mono (수치·라벨) |
| 바탕 / 패널 | #FFFFFF / #F7F8FA |
| 글자 | #111111 · 보조 #4B5563 · 흐림 #8A8F98 |
| 선 | #E6E8EC (1px), 아주 연한 선 #F0F1F3 |
| 포인트 | 검정 #111111 (버튼), 파랑 #3182F6 (값·링크) |
| 상태 | 성공 #12A66B · 경고 #F5A623 · 오류 #E5484D |
| 과목 | 물리 #2F6BFF · 화학 #F0640A · 생명 #12A66B · 지구 #7A5AF8 |
| 라운드 | 패널 12px · 버튼/입력 8px · 썸네일 10px |

다크 모드는 사이트 셸에만 적용된다 (`:root[data-theme="dark"]`). 실험 화면은 항상 밝은 바탕이다.

## 레이아웃

- **상단 바 56px**: 워드마크 → 과목 탭(밑줄 2px) → 검색(⌘K) · 테마 · 실험 등록(검정 버튼). 모든 화면에서 고정.
- **페이지**: 최대 폭 1280px, 좌우 28px. 제목 30px/600, 제목 줄 오른쪽에 필터(글자만).
- **카드 그리드**: 5열(≥1100px) → 4 → 3 → 2(모바일). 썸네일 16:10, 1px 선, 10px 라운드. 제목 14.5px/600, 메타 12.5px 흐림.
- **뷰어**: 상단 바 + 보조 바 46px(과목 / 실험 이름 · 실험 탭 · 정보·전체화면·새 창) + 실험 iframe 전체. 정보 패널 320px 오른쪽.
- **모바일(≤720px)**: 상단 바 아래 과목 탭 줄(가로 스크롤), 카드 2열, 뷰어 탭은 가로 스크롤.

## 실험 HTML 컴포넌트 (lab-theme.css)

| 클래스 | 쓰임 |
|---|---|
| `.lab-header` `.lab-brand` `.lab-tabs` | 단독 실행 시 상단 제목·탭. 임베드 시 자동 숨김 |
| `.lab-main` `.lab-title` `.lab-page(.active)` | 본문·제목·실험 영역 |
| `.status` | 상단 상태줄. `라벨 <b>값</b>`, 오른쪽 메시지 `.msg` |
| `.canvas-wrap` | 캔버스 바탕 (#F7F8FA, 1px 선). 위아래 붙이기 `.stack-top` `.stack-bot` |
| `.controls > .control` | 조작부. `label` + `.slider`([-] range [+]) + `.value` |
| `.btn` `.btn-primary` `.btn-accent` `.btn-ghost` `.btn-sm` `.btn-icon` `.btn-block` | 버튼 |
| `.seg > button.selected` | 분절 선택 버튼 (SC/BCC/FCC 같은 택일) |
| `.panel` `.panel h3` | 흰 패널과 패널 제목 |
| `.field` + `select`/`input.narrow` | 라벨-입력 한 줄 |
| `.note` `.note-ok` `.note-err` | alert 대신 쓰는 인라인 메시지 |
| `.big-value` `.kv` `.tag` `.legend` | 큰 수치, 키-값 줄, 작은 태그, 범례 |
| `.grid-2` `.grid-3` `.stack` `.row` | 레이아웃 |

캔버스 안에서 쓰는 색도 같은 토큰을 쓴다. 물 #3182F6, 용질 #F5A623, 강조 #E5484D, 축 #C9CED6, 글자 #111111, 흐린 글자 #8A8F98.

## 썸네일

실제 실험 화면을 캡처한다. 그래프·장치가 보이는 영역을 16:10 으로 잘라 폭 800px 정도로 저장한다. 글자 위주 화면보다 도형·그래프가 있는 화면이 카드에서 잘 읽힌다.
