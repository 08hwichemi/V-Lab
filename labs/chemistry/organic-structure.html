과제: 이성질체 찾기

진행0 / 0
그리는 방법 왼쪽 버튼에 마우스를 올리면 설명이 나옵니다
  • 결합 을 고르고 빈 곳을 드래그하면 탄소–탄소 결합이 생깁니다. 끝 원자에서 다시 드래그하면 사슬이 이어지고, 사슬 로 드래그하면 한 번에 여러 개가 그려집니다.
  • 결합을 다시 클릭하면 단일 → 이중 → 삼중 결합으로 바뀝니다.
  • O N 같은 원소 버튼을 누른 뒤 원자를 클릭하면 그 원소로 바뀝니다. 수소는 자동으로 채워지므로 그리지 않아도 됩니다.
  • 고리는 삼각~벤젠 을 누르고 빈 곳을 클릭합니다. 지우개 로 지우고, 되돌리기 로 한 단계 취소합니다.
  • 골격 구조식에서는 탄소와 수소를 생략합니다. 어렵다면 편집기에 탄소 글자 표시를 켜고, 오른쪽에서 펼친 구조식과 비교해 보세요.
  • 과제 제출 시 그린 구조는 원자의 연결을 표준 코드로 바꿔 비교합니다. 모양이나 방향이 달라도 연결이 같으면 같은 물질, 분자식이 같고 연결이 다르면 이성질체로 판정됩니다.
