도움말

🎯 학습 목표

  1. 원자의 원자가 전자를 루이스 전자점식으로 나타낼 수 있다.
  2. 옥텟 규칙을 이용하여 분자와 다원자 이온의 루이스 전자점식을 그릴 수 있다.
  3. 루이스 전자점식에서 공유 전자쌍과 비공유 전자쌍을 구별하고 그 수를 셀 수 있다.
  4. 공유 전자쌍을 결합선으로 바꾸어 루이스 구조식으로 나타낼 수 있다.

📐 루이스 전자점식 그리는 순서

  1. 원소 카드의 점으로 각 원자의 원자가 전자를 확인한다. (음이온은 전하만큼 전자를 더 받고, 양이온은 잃는다)
  2. 골격을 정한다. 보통 개수가 적고 전기 음성도가 작은 원자가 중심, H는 항상 바깥쪽.
  3. 중심 원자와 주변 원자를 단일 결합으로 연결한다.
  4. 남은 전자로 주변 원자부터 비공유 전자쌍을 채워 옥텟(H는 2개)을 만든다.
  5. 중심 원자의 옥텟이 부족하면 주변 원자의 비공유 전자쌍을 다중 결합으로 바꾼다.
  6. 형식 전하를 확인해 가장 작은 구조를 고른다. (심화)
  7. 완성한 구조에서 공유 전자쌍 수와 비공유 전자쌍 수를 센다.

🛠 도구

  • 원자: 빈 곳을 클릭하면 선택한 원소를 놓아요. 원자에서 바깥으로 끌면 공유 전자쌍으로 연결된 새 원자가 생기고, 다른 원자까지 끌면 두 원자 사이에 공유 전자쌍이 생겨요. 원자를 클릭하면 선택한 원소로 바뀌어요.
  • 공유 전자쌍: 원자 두 개를 차례로 클릭하면 사이에 공유 전자쌍 1개가 생겨요. 공유 전자쌍을 클릭할 때마다 1쌍씩 늘어나요(최대 3쌍 = 삼중 결합). 우클릭(Shift+클릭)하거나 두 번 탭(더블 클릭)하면 1쌍 줄어요.
  • 비공유 전자쌍: 원자를 클릭하면 비공유 전자쌍이 하나씩 추가돼요. 전자쌍을 클릭하거나 두 번 탭(더블 클릭)하거나, 원자를 우클릭(Shift+클릭)하면 하나 지워져요.
  • 이동: 원자를 끌어서 옮겨요. 지우개: 원자는 통째로, 전자쌍은 1쌍씩 지워요.
  • 두 번 탭(더블 클릭): 이동·지우개 도구에서 원자를 두 번 탭하면 원자가, 전자쌍을 두 번 탭하면 그 전자쌍 1쌍이 지워져요. (공유쌍·비공유쌍 도구에서는 빠르게 두 번 눌러도 추가로 처리돼요)
  • 확대·축소: 보드 오른쪽 아래의 − / + 버튼, 마우스 휠, 또는 두 손가락 벌리기로 확대해요. 빈 곳을 끌면 보드가 움직이고, ⤢ 버튼은 그림 전체가 보이게 맞춰 줘요.
  • 옥텟 확인 표시: 옥텟 규칙을 아직 만족하지 않는 원자(H, B, Be 제외)는 노란색으로 반짝여요. PC는 마우스를 올리면, 휴대폰은 원자를 꾹 누르면 안내가 나오고, 바르게 고치면 표시가 사라져요.
  • 확장된 옥텟 안내: 3주기 원소 주위 전자가 10개나 12개가 되면 원자에서 선이 뻗어 [심화 개념] 안내가 나와요. ✕를 누르면 닫혀요.
  • 쌍극자 모멘트·부분 전하: 체크하면 극성 공유 결합마다 쌍극자 모멘트 화살표(δ+ → δ−, 꼬리에 +)가 나오고, 각 원자에 부분 전하 δ+ / δ−가 표시돼요. 화살표는 전기 음성도가 큰 원자 쪽을 가리켜요.
  • 결합선으로 바꾸기: 전자점식(공유 전자쌍을 점으로)과 구조식(공유 전자쌍 1개 = 결합선 1개)을 오가며 볼 수 있어요.

🎨 화면 표시 안내

노란색 반짝임 — 옥텟 규칙을 아직 만족하지 않는 원자예요(H·B·Be 제외). 바르게 고치면 사라져요. PC는 마우스를 올리고, 휴대폰은 꾹 누르면 안내가 보여요.
초록 원 (옥텟 상태 표시를 켰을 때) — 옥텟 규칙을 만족해요. H는 전자 2개(듀엣)일 때 초록색이에요.
주황 원 (옥텟 상태 표시를 켰을 때) — 옥텟 규칙의 예외예요. B는 전자 6개, Be는 4개, 3주기 원소의 확장된 옥텟(10·12개)이 여기에 해당해요.
빨간 점선 원 (옥텟 상태 표시를 켰을 때) — 옥텟 규칙을 만족하지 않아요.
주황 말풍선 — 확장된 옥텟 규칙을 가진 원자를 알려 줘요(심화 개념). ✕로 닫을 수 있어요.
동그라미 속 + / − / 0 (형식 전하 표시) — 각 원자의 형식 전하예요. 파란 +, 빨간 −, 회색 0.
청록 화살표 (쌍극자 모멘트 표시) — 극성 공유 결합의 쌍극자 모멘트예요. 꼬리의 +는 δ+ 쪽, 화살촉은 전기 음성도가 큰 δ− 쪽이에요.
δ+ / δ− (부분 전하) — 전자를 덜 끌어당기는 원자는 δ+(파랑), 더 끌어당기는 원자는 δ−(빨강)예요.
파란 점 / 빨간 점 (공유·비공유 색 구분) — 파란 점은 공유 전자쌍, 빨간 점은 비공유 전자쌍이에요.
보라 점선 원 — 공유쌍 도구로 고른 원자예요. 이어서 연결할 원자를 누르세요.
O 1/1 미션 칩 — 필요한 원자 수와 지금 그린 수예요. 초록은 개수가 맞음, 빨강은 너무 많음, 회색은 아직 부족함이에요.
심화 분홍 점선 밑줄 글자 — 고등학교 범위를 넘는 심화 개념이에요. 마우스를 올리거나 누르면 설명이 나와요.
